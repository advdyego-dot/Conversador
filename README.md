# Conversador

Intérprete de bolso: toque em quem vai falar, fale, faça uma pausa e ouça a tradução em voz alta.

- Português ↔ Inglês, Espanhol, Francês, Italiano, Alemão, Chinês ou Japonês.
- O fim da fala é detectado por uma pausa (ajustável de 0,8 s a 3 s).
- O microfone e a voz funcionam no Chrome (computador ou Android) e no app Claude para computador.
  Nos apps de celular e no Safari, use o campo de texto (o microfone do teclado funciona).

`index.html` é publicado como Artifact no claude.ai, com as capacidades `dictation`, `sample` e `tts`.
